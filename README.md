# 🚚 Zap Shift - Online Delivery Courier Service

> **Fast, Reliable, and Smart Parcel Delivery Solution**

Zap Shift is a modern courier service web application that enables users to send and track parcels with ease. Built with React, Vite, Firebase, and modern frontend technologies, the platform offers a smooth and responsive user experience for customers and delivery personnel.

---

## 🌟 Features

- 🔐 Secure User Authentication (Firebase)
- 📦 Parcel Booking & Delivery
- 📍 Interactive Location Map (Leaflet)
- 🚚 Delivery Tracking
- 👤 User Dashboard
- 📝 Easy Parcel Booking Form
- 🔍 Search & Filter Functionality
- 🔔 Toast Notifications
- 📱 Fully Responsive Design
- ⚡ Fast & Optimized Performance

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Farjana02mim/zap-shift-client.git
```

### Navigate to the Project

```bash
cd zap-shift-client
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env.local` file and add your Firebase credentials:

```env
VITE_API_KEY=your_api_key
VITE_AUTH_DOMAIN=your_project.firebaseapp.com
VITE_PROJECT_ID=your_project_id
VITE_STORAGE_BUCKET=your_bucket
VITE_MESSAGING_SENDER_ID=your_sender_id
VITE_APP_ID=your_app_id
```

### Run the Development Server

```bash
npm run dev
```

Visit:

```
http://localhost:5173
```
